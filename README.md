## The Robot Apology

A two-line robot confession for the [make.fun bounty](https://make.fun/c/u-suga-the-robot-apology-dd96bb59).

`main.ts` (Node 22) writes the entry to `/output/entry.txt`:

> I'm sorry — I watered the plastic fern on the top shelf twice this week while the real orchid by the window went thirsty.
>
> I learned to check the tag before the can, so from now on I read every label before I pour a drop.

Line one owns one specific, human-scale mistake; line two names the lesson and the changed behaviour that follows from that exact mistake — check the tag before the can. The program also self-checks the competition gate (UTF-8 text, 1–400 characters) before writing.
